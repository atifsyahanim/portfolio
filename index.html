Deep Learning · Audio Processing

Voice Pathology Detection

A convolutional neural network (CNN) trained to classify voice recordings as healthy or pathological, using Mel-frequency cepstral coefficients (MFCCs) as input features.

Tech Stack

Python TensorFlow / Keras Keras-CV Librosa SoundFile PyDub WebRTC VAD Audiomentations NumPy Matplotlib Seaborn Scikit-learn HuggingFace Gradio HTML/CSS

What I Did

  • Acquired voice samples from Hospital UiTM Puncak Alam (HASA) and self-collected data
  • Extracted MFCC and spectral features using Librosa, and further preprocessing
  • Applied augmentations (time-stretching, pitch-shifting) to handle class imbalance and increase dataset size
  • Designed and trained a ResNet-based CNN for audio classification
  • Evaluated performance with accuracy, F1-score, and confusion matrices
  • Deployed the model into a web-based prototype and published on HuggingFace
  • Results are validated by an expert in ENT

RAG · LLM · NLP

RAG Chatbot – The Glory

A small-scale Retrieval-Augmented Generation (RAG) prototype built to query a PDF about the K-drama The Glory. The chatbot answers questions factually using chunks from the document. Note: This is a testing model for learning purposes.

Tech Stack

Python Streamlit LangChain Sentence Transformers FAISS PyPDF2 HuggingFace Transformers Self-Learn

What I Did

  • Extracted text from a Wikipedia PDF about The Glory K-drama
  • Split text into chunks for context using LangChain
  • Created embeddings for each chunk using Sentence Transformers
  • Built a FAISS vector database to retrieve relevant chunks based on user queries
  • Integrated a HuggingFace LLM to generate answers from retrieved chunks
  • Designed a Streamlit chatbot interface
  • Emphasized that this is a small, experimental RAG model for learning purposes
